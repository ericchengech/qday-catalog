Typical agent flow

1. GET  https://qday-catalog.xynaptic.io/product/1      -> 402 + accepts[0] terms
2. Sign EIP-3009 TransferWithAuthorization (tUSD8, domain "tUSD8" v2, chain 44005)
3. POST facilitator /verify with the signed payload    -> isValid: true
4. GET  /product/1 with header X-PAYMENT: base64(payload)
   -> 200, X-PAYMENT-RESPONSE header, JSON deliverable
